# PortSwigger Web Security Labs

Hands-on practice with web application security vulnerabilities using the
[PortSwigger Web Security Academy](https://portswigger.net/web-security).

This project documents the labs completed during my cybersecurity learning
journey, along with screenshots and a consolidated report of the work.

##  Overview

The project focuses on understanding common web application vulnerabilities
through practical, intentionally vulnerable lab environments.

The labs helped build familiarity with identifying vulnerabilities,
understanding their impact, and applying appropriate security concepts.

##  Topics Covered

- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- API Security
- Server-Side Request Forgery (SSRF)
- Cross-Origin Resource Sharing (CORS)
- Mass Assignment
- Unused API Endpoints
- API Endpoint Documentation

#  Methodology
The labs were approached by:
1. Understanding the vulnerability and its underlying concept.
2. Examining the application's behavior.
3. Identifying relevant attack surfaces or parameters.
4. Testing the vulnerability within the provided lab environment.
5. Verifying the result.
6. Documenting the process and outcome with screenshots.
   
# Learning Outcomes
Through these labs,practical exposure was gained to:
- Web application attack surfaces
- Common OWASP-style vulnerabilities
- HTTP requests and responses
- API security concepts
- Vulnerability identification and validation
- Web security testing methodology
- Security documentation and reporting

## Disclaimer
All testing documented in this repository was performed against PortSwigger's
intentionally vulnerable lab environments for educational purposes.
No unauthorized systems were targeted.
